FAQ

Questions, answered.

Is Orchestra free?

Yes. Orchestra is free and open source, under the MIT license.

Which agents can I use?

Any agent that runs in a terminal: Claude Code, Codex, Antigravity, Aider, Qwen Code, OpenCode, Copilot CLI, Cursor CLI, Goose, Amp, Kimi… or your own command. Status tracking, Relay, Delegation and roles are built for Claude Code and Codex; other agents get a status based on terminal activity.

Do I need an API key?

No. Orchestra launches the CLIs you already installed and logged in, with your own subscriptions.

Does my code leave my machine?

Orchestra itself sends nothing anywhere. Your agents talk to their own providers exactly as they do in a normal terminal.

Can two agents loop forever?

No. Every link has a turn limit (3 by default, up to 20), and you can switch any link off in one click. Every exchange shows up in the log.

Mac or Linux?

Windows 10 and 11 for now.

Windows says "Windows protected your PC".

The installer isn't code-signed yet, so SmartScreen doesn't know it. Click More info, then Run anyway. The source code is public on GitHub.
