Requirements

  • Windows 10 or 11, 64-bit.
  • The agent CLIs you want to use, installed and logged in: claude or codex must already work in a normal terminal.
  • Your existing subscriptions. Orchestra starts the CLIs logged in with your own accounts.
  • Git, for branches: an agent moved to a branch runs in its own git worktree.
  • MIT license. No Orchestra account to create.

What Orchestra writes on your PC

  • %APPDATA%\Orchestra: settings, boards, custom agent logos (logos), the per-session hook files of Claude Code (hooks), and usage-probe, a folder where Orchestra runs Claude Code in the background to read your usage. The exchange log stays in memory.
  • ~/.claude.json: a folder opened with Claude Code is marked as trusted, so Claude does not ask again (can be turned off in Settings › General). Hooks and the MCP server are passed to each Claude Code session at launch; your Claude settings files are not changed.
  • ~/.codex/orchestra.config.toml, a separate Codex profile with Orchestra's MCP server (your config.toml is never changed), and Orchestra's own entries in ~/.codex/hooks.json. Both are written when the app starts and do nothing when Codex runs outside Orchestra.
  • The hooks and the MCP server only talk to the app on 127.0.0.1, with a token that changes at every launch.

Uninstall

Windows Settings › Apps › Installed apps (Windows 11) or Apps & features (Windows 10) › Orchestra › Uninstall. The uninstaller leaves your data: to remove everything, also delete %APPDATA%\Orchestra, ~/.codex/orchestra.config.toml and the entries of ~/.codex/hooks.json that contain ORCHESTRA_HOOK_URL. The trusted-folder entries written to ~/.claude.json also stay; they belong to Claude Code's own list of trusted folders.

FAQ

Which agents can I use?

Any agent that runs in a terminal: Claude Code, Codex, Gemini CLI, Antigravity, Aider, Qwen Code, OpenCode, Copilot CLI, Cursor CLI, Goose, Amp, Kimi CLI, Hermes Agent… or your own command. Relay, delegation, roles and precise status are built for Claude Code and Codex. Other agents get a status from terminal activity and can receive relayed messages.

Do I need an API key?

No. Orchestra launches the CLIs you already installed and logged in, with your own subscriptions.

Does my code leave my machine?

Orchestra itself sends nothing anywhere. Your agents talk to their own providers exactly as they do in a normal terminal.

Can two agents loop forever?

No. Every link has a turn limit (3 by default, up to 20), and you can switch any link off in one click. Every exchange shows up in the log.

Will it use up my subscription faster?

It can. Every tile uses your own plan, and linked agents that keep handing work to each other add up quickly. Keep turn limits low and switch links off when you don't need them.

What can the agents do on my PC?

The same as in your own terminal: each tile runs the real CLI in the folder you picked, with that CLI's usual permission settings. Orchestra never approves a permission request for an agent. Its own tools are pre-approved, except running a command in a linked terminal, which always asks first.

Mac or Linux?

Not yet: Orchestra runs on Windows 10 and 11 only for now. Follow the project on GitHub to hear when that changes.
